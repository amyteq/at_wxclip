# evals

固定样本 + 校验脚本，用来回答两个问题：

1. **解码是否仍然有效** —— WeChat 更新后 URL 形态或密钥推导常会变，这里放脱敏后的
   URL 样本与期望解码结果；
2. **提取/总结质量是否退化** —— 截屏、文字提取、总结的 prompt 变更前后对比。

改动 decoder 或 prompt 之前，先在这里补一个有代表性的样本。

体积大的视频/音频样本不进 Git：放外部网盘，并在本文件登记来源、大小与 `sha1sum`。
