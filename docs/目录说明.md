# 目录说明

结构刻意保持扁平、克制：一层目录说清职责，避免 `src/` 之类的额外嵌套。

| 路径       | 职责                                                                 |
|------------|----------------------------------------------------------------------|
| `wxclip/`  | Python 包，可 `python -m wxclip` 运行；模块按职责拆：proxy / capture / keystream / decrypt / downloader / pipeline / server |
| `web/`     | 注入页面的 hook 脚本、前端页面；构建产物不进 Git（keystream 自 M1 起在 Python 侧） |
| `docs/`    | 背景、计划、规格、协议发现记录                                         |
| `tests/`   | pytest 测试，文件名对应被测模块（`test_<module>.py`）                  |
| `scripts/` | 给人手动执行的入口（环境准备、抓包会话、批量处理）                      |
| `tools/`   | 辅助小工具，不属于交付包，允许糙一点                                    |
| `evals/`   | 固定样本 + 校验脚本：解码是否仍然有效、提取/总结质量是否退化            |
| `temp/`    | 临时文件，git 忽略，随时可删                                           |

## 什么不进 Git

- 抓取到的视频、截图、音频（`downloads/`、`captures/`、`*.mp4`、`*.m4s`）
- 抓包记录（`*.har`、`*.pcap`）与代理 CA 证书/私钥
- `.env`、任何 token 与 cookie
- 本机个人配置 `.claude/settings.local.json`（模板见 `.example`）
- 依赖与构建产物（`.venv/`、`node_modules/`、`dist/`）

体积大但需要留存的样本，放外部网盘并在 `evals/README.md` 里登记来源与校验值，
不要塞进仓库。
