## 产品功能

- 开发一个 headless tool（with a light web server）and frontend as GUI
- 启动一个代理服务器并在 wechat for Linux app 中设置使用此代理
- 这样在 wechat 中播放此视频就能捕捉到请求地址
- 再经过 decoder 来解析出真实的下载地址
- 这样通过本 python tool 可以直接下载视频（不走代理）
- 视频可以进一步做截屏，文字提取，总结等操作

## 主要技术栈

- main tech stack: python + javascript / typescript
  - assumption: wechat running on linux box
  - python: implement a proxy server so we can capture the target links; also implement a
    server to serve admin and download dashboard
  - javascript: some frontend pages, also to decode the actual address of video contents

## 待确认的前提

以下几点会直接影响设计，动手前先确认：

1. Linux 版 WeChat 的代理设置方式（应用内设置 / 系统代理 / 环境变量），以及是否需要
   给它信任本地 CA 才能看到 HTTPS 请求。
2. 视频内容走的是 HTTP 还是 HTTPS，是整段文件还是分片（m3u8 / m4s）。
3. `decrypt.js` 的解密输入究竟来自 URL 参数、响应头还是本地缓存文件，能否在纯
   Node 环境里复用，而不必带上 Electron。
4. 截屏与文字提取的落地方式（ffmpeg + OCR 引擎）与是否需要本地模型。
